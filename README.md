## 🚀 Local Development

1. Clone repository:
   ```bash
   git clone https://github.com/MinnNgoc2702/Portfolio.git
   cd Portfolio
   ```

2. Run with any local server:
   ```bash
   # Using Python:
   python -m http.server 3000

   # Or using Node.js:
   npx serve .
   ```

3. Open `http://localhost:3000` in your browser.

## ☁️ Deployment

Configured for instant static deployment on [Vercel](https://vercel.com):

1. Import this repository `MinnNgoc2702/Portfolio` in Vercel.
2. Leave framework preset as **Other** (Root directory: `./`).
3. Click **Deploy**.
